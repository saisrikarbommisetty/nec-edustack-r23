# 🎓 NEC EduStack R23 — Your Academic Stack, Simplified

EduStack R23 is a centralized academic platform designed to streamline access to study materials for B.Tech students under the R23 regulation.

It eliminates scattered resources by providing a unified, intuitive system to browse, access, and manage notes, PPTs, and previous year questions across all years and branches.

---

## 🌐 Live Product

👉 https://nec-edustack.vercel.app

---

## 🧠 Problem

Academic resources are fragmented across WhatsApp groups, Google Drives, and personal networks.
Students waste time searching instead of learning.

---

## 💡 Solution

NEC EduStack R23 brings everything into a single structured platform:

* Organized by **Year → Branch → Subject**
* Instant access to curated materials
* Clean, responsive interface for all devices

---

## ✨ Key Features

* 📚 Centralized Notes, PPTs, and PYQs
* 🔍 Structured navigation (Year / Branch / Subject)
* ⚡ Fast and responsive UI
* ☁️ Supabase-powered backend (Storage + DB)
* 🔐 Secure access with environment-based configuration
* 🚀 Continuous deployment with Vercel

---

* Environment variables manage secure configuration
